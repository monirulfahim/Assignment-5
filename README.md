### Answer 1 :
1.var
It is the old way to create variables (before ES6).
You can re-declare the same variable.
You can change the value.
It has function scope.

2.let
Introduced in ES6 (modern JavaScript).
You cannot re-declare the same variable.
You can change the value.
It has block scope (works inside { } blocks).

3.const
Also introduced in ES6.
You cannot re-declare the variable.
You cannot change the value.
It also has block scope

### Answer 2 :

The spread operator (...) in JavaScript is used to expand or spread the elements of an array or object.

### Answer 3 :
1.map()
Used to create a new array.
It changes or transforms each element.
Always returns a new array

2.filter()
Used to select elements based on a condition.
Returns a new array with matching elements only.

3.forEach()
Used to loop through an array.
It does not return a new array.
Mostly used for printing or doing actions.

An arrow function is a shorter way to write a function using => in JavaScript.

Template literals are strings written with backticks ( ) that allow variables and expressions inside ${} and support multi-line text.
